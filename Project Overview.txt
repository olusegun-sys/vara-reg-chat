## 1. What We're Building

A **Retrieval-Augmented Generation (RAG) chat interface** for querying regulatory rulebooks. A user types a question in a chat window; the system retrieves the most relevant chunks from a regulatory PDF, passes them to an LLM with strict citation rules, and returns a grounded answer with page references. 

**Why it exists:** Banks and VASPs struggle to navigate sprawling regulatory rulebooks. An uncited answer is worthless in compliance. This tool answers *only* from the document, cites every claim, and refuses when the answer isn't in the source.

**Current Corpus:** VARA Compliance and Risk Management Rulebook (19 May 2025). 
*(Note: The Company, Technology, and Market Conduct rulebooks were removed to ensure absolute stability for the demo. We hit a text encoding bug during ingestion that corrupted the 2,500-chunk database. The architecture remains fully capable of scaling to all rulebooks post-demo).*

## 4. Architecture & Design Decisions (Validated)

1. **Streaming (SSE) Architecture:** The `/api/chat/stream` endpoint yields Server-Sent Events. The frontend reads the stream and updates the text word-by-word, eliminating the 5-10 second wait.
2. **Cloud Embeddings (Cohere):** Replaced Gemini to bypass the hard 1,000 requests/day limit. Cohere's trial tier allows 100,000 tokens per minute, making ingestion of large documents reliable.
3. **Database Storage (Supabase):** Chat sessions and messages are saved in PostgreSQL via Supabase. Clearing browser cache no longer deletes chats.
4. **Premium UI/UX:** Total dark mode. Sidebar is deep navy (`#0F172A`). Main chat background is slightly lighter navy (`#1E293B`). Chat input is a glowing, rounded pill.
5. **Mobile Responsiveness:** Hamburger menu added for mobile views to toggle the sidebar. Header is cleanly aligned with the jurisdiction selector.
6. **Action Buttons:** Messages have copy, edit (for users), and thumbs up/down/share (for AI) with custom CSS tooltips.
7. **Reset-able ingestion.** `--reset` flag prevents duplicate vectors.
8. **Smart Titles.** A dedicated `/api/title` endpoint uses `llama-3.1-8b-instant` to generate a 3-5 word summary for the sidebar.

## 6. Roadblocks & Resolutions (Complete History)

1. **`notepad++` not recognized** → `start notepad++ "file"`. ✅
2. **`pip install` failed on Python 3.14** → Chroma's `chroma-hnswlib` link error. **Resolution:** swapped Chroma → FAISS, bumped pydantic ≥2.13.0. ✅
3. **`/api/chat` 502 `proxies` error** → `openai==1.54.0` vs `httpx>=0.28`. Bumped to `openai>=1.55.3`. ✅
4. **Markdown rendering issue** → Installed `react-markdown`. ✅
5. **Slow Response Time (Blocking)** → Implemented Server-Sent Events (SSE). ✅
6. **Input "Red Circle" Bug** → Ensured `preventDefault()` on the `Enter` keydown handler. ✅
7. **Clearing Cache Deletes Chats** → Migrated to Supabase PostgreSQL. ✅
8. **GitHub Push Protection Error** → Real API keys were accidentally committed. **Resolution:** Reset git history (`git init`), replaced the keys with placeholders, force-pushed. ✅
9. **Render Deployment Port Scan Timeout** → The Start Command `--port $PORT` wasn't expanding. **Resolution:** Wrapped the command in `sh -c "uvicorn ... --port $PORT"`. ✅
10. **Render Deployment Out of Memory (512MB)** → `sentence-transformers` loaded PyTorch at startup. **Resolution:** Migrated to cloud embeddings. ✅
11. **Gemini Embedding Rate Limits (429)** → Free tier limit is 100 requests per minute / 1000 per day. **Resolution:** Migrated to Cohere. ✅
12. **Cohere API Key Header Error** → Trailing newline in Render env var caused `Illegal header value`. **Resolution:** Added `.strip()` to `config.py` and fixed Render dashboard. ✅
13. **Corrupted Text Encoding** → Notepad++ saved `.txt` files in ANSI/UTF-16, causing gibberish chunks. **Resolution:** Reverted to the stable 202-chunk Risk Management PDF for the demo. ✅
