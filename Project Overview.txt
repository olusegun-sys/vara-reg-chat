## 1. What We're Building

A **Retrieval-Augmented Generation (RAG) chat** for querying global regulatory rulebooks. The user picks a jurisdiction, asks a question, and the system retrieves the most relevant chunks from FAISS and BM25, passes them to an LLM with strict citation rules, and returns a grounded answer.

**The AI acts as a conversational compliance colleague.** It explains the "why" behind rules, uses analogies, and answers follow-up questions naturally — while strictly anchoring every legal fact to the retrieved sources.

**If the answer isn't in the internal corpus, the system searches the live web via Tavily and Serper — restricted to authoritative sources.** If the web search returns nothing trusted, the app *honestly refuses* rather than hallucinating a citation.

## 4. Architecture & Design Decisions (Validated)

1. **Hybrid Search (BM25 + FAISS):** Reciprocal Rank Fusion (RRF) merges semantic vectors from FAISS with exact keyword matches from BM25.
2. **Critic Agent (Reflexion):** Before the answer reaches the user, a fast LLM check flags hallucinations and missing citations. **Fails open** — if the Critic can't run, the answer ships anyway.
3. **Perplexity-Style Source Drawer:** "📚 X Sources" pill in the chat bubble → slide-out panel with snippets, tiers, deep links.
4. **Conversational Synthesis Prompt:** Explains the "why", uses analogies, anchors every legal fact to a retrieved chunk.
5. **Role Classification Precision (EU AI Act):** Distinguishes Provider from Deployer.
6. **Draft Persistence:** Unsent text saved to `localStorage` per session.
7. **Phase 3 Evals (LLM-as-a-Judge):** `eval/run_eval.py` scores answers 1–5. `golden_dataset.json` has 20 hard questions.
8. **Cohere Timeout Resilience:** `retrieval.py` wraps Cohere embed in a 2-retry loop with 15-second timeout.
9. **SSE streaming with heartbeat:** `/api/chat/stream` yields SSE events; during long blocking phases the backend emits `: keep-alive\n\n` every 2s. **Headers:** `Cache-Control: no-cache`, `Connection: keep-alive`, `X-Accel-Buffering: no`. **Uvicorn:** `--timeout-keep-alive 120`.
10. **Cloud embeddings (Cohere)** — replaced local PyTorch to kill Render OOM bugs.
11. **Per-browser privacy (Supabase)** — unique `vara_browser_id` in `localStorage`.
12. **Conversational memory** — smart window (first 2 + last 8) to the LLM.
13. **Jurisdiction-aware query rewriter** — skips for short (<8 words) AND very long (>40 words) questions.
14. **Smarter Three-Trigger Web Fallback:** out-of-scope token, low FAISS confidence, post-generation LLM refusal.
15. **Dual-Provider Web Search:** Tavily first, Serper merges if Tavily returns <2 results.
16. **Honest refusal:** refuses rather than hallucinates when no authoritative source exists.
17. **Citation deep-linking:** `retrieval.py` appends `#page=X&search="phrase"` to PDF URLs.
18. **VARA Part Mapping:** `retrieval.py` maps page ranges to VARA "Part 1, Part 2" names.
19. **4-Tier LLM Waterfall (CURRENT ORDER):** **Groq → Gemini → OpenRouter → Cloudflare**. (Gemini moved up from tier 3 on 2026-11-08 because its daily limits are more generous than Groq's; Cloudflare added as Tier 4 on 2026-11-09 for additional resilience.)
20. **Token Ceiling Management:** `TOP_K_RESULTS = 5`, `LLM_MAX_TOKENS = 1500`, Critic `max_tokens=200` with `reasoning_effort="low"`.
21. **Dynamic Retrieval Broadening:** Low FAISS confidence triggers a broader keyword search.
22. **Query Hints:** `QUERY_HINT_MAP` forces retrieval of the Omnibus deadline, Article 50, and Cabinet Decision 111.
23. **Prompt Injection Guard:** Refuses "ignore previous instructions".
24. **Article Verification:** Forbids guessing article numbers; cites by page if unsure.
25. **Cold-Start UX:** `client.js` waits 4 seconds, then shows "Warming up the AI…".
26. **Cron Keep-Alive:** cron-job.org pings `/api/health` every 10 minutes.
27. **Critic portability warning:** `reasoning_effort="low"` is **Groq-specific**. Do NOT route Critic to Gemini/OpenRouter/Cloudflare without branching out that parameter.
28. **Client timeout 15s (all tiers)** — healthy calls finish in 2–10s; stuck tiers fail fast so the chain doesn't hang for minutes.
29. **`validate_config()` requires at least one LLM tier** (Groq OR Gemini OR OpenRouter OR Cloudflare), not Groq specifically. Enables forced-fallback testing.
30. **Cloudflare endpoint pattern:** `OpenAI(api_key=CLOUDFLARE_API_TOKEN, base_url=f"https://api.cloudflare.com/client/v4/accounts/{CLOUDFLARE_ACCOUNT_ID}/ai/v1")`. Account ID embedded in URL, so client is constructed per-call.

67. **🟢 `gemini-2.0-flash` shut down (June 1, 2026)** → Updated `GEMINI_MODEL` to `gemini-3.8-flash`.

Root cause: `openai/gpt-oss-120b` is a reasoning model; without `reasoning_effort="low"` it burns the token budget on hidden reasoning. Fixed with `reasoning_effort="low"` + `max_tokens=200` + empty-response fail-open guard. **Verified locally 2026-11-09** — `[critic] Result: 'PASS'` on a correct answer.
69. **🟢 OpenRouter 404 on `meta-llama/llama-3-70b-instruct`** → `.env` had stale override. Fixed to `meta-llama/llama-3.3-70b-instruct:free`. Verified via config read; end-to-end pending.
70. **🟢 Critic false-positive `'FAIL'` on correct answers** → Original `CRITIC_PROMPT` was too broad; it treated legitimate paraphrasing as hallucination. Fixed by rewriting `CRITIC_PROMPT` with an explicit **"WHAT NOT TO FLAG"** section (paraphrase, summarization, page-citations, minor wording differences) and stricter FAIL criteria ("clearly present"). **Verified locally 2026-11-09** — PASS on first attempt, no retry triggered.

72. **🟢 5-minute hang on a query (2026-11-09 early)** → Root cause: 60s client timeouts × 4 tiers = up to 4 minutes when the chain falls through. Fixed by lowering all three `OpenAI(...)` client timeouts to 15s. Worst case now: 4 × 15s = 60s. **Verified — no more hangs.**
