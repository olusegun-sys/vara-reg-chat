## 1. What We're Building

A **Retrieval-Augmented Generation (RAG) chat interface** for querying global regulatory rulebooks. A user selects a jurisdiction, types a question, and the system retrieves the most relevant chunks. It passes them to an LLM with strict citation rules and returns a grounded answer. **If the answer isn't in the internal docs (or the user asks about a jurisdiction not yet ingested), it automatically falls back to a live Tavily web search**, synthesizing an answer with clickable web references.

**Why it exists:** Banks, fintechs, and VASPs struggle to navigate sprawling regulations (e.g., Dubai VARA, EU AI Act, UK FCA). An uncited answer is worthless in compliance. This tool answers *only* from the documents or live web data, cites every claim, and refuses when the answer isn't found.

## 4. Architecture & Design Decisions (Validated)

1. **Streaming (SSE) Architecture:** `/api/chat/stream` yields Server-Sent Events. SSE parser uses proper `\n\n` buffering to prevent JSON truncation errors.
2. **Cloud Embeddings (Cohere):** Replaced local PyTorch embeddings to avoid Render 512MB OOM crashes.
3. **Database Storage & Privacy (Supabase):** Unique `vara_browser_id` in `localStorage` isolates sessions per browser.
4. **Conversational Memory:** Frontend sends history (smart-window: first 2 + last 8 messages) to backend.
5. **Jurisdiction-Aware Query Rewriter:** Fast LLM call rewrites vague questions. **CRITICAL UPGRADE:** A deterministic Python post-processor (`_postprocess_rewrite`) now sanitizes the LLM's output. It detects truncated responses and strips service-type words (e.g., "custody") when the topic is cross-cutting (e.g., "AML"). This prevents the LLM from retrieving the wrong rulebook.
6. **Multi-Jurisdiction System Prompt:** The LLM is explicitly told which jurisdiction it is answering for, to prevent cross-contamination. It is permitted to answer out-of-scope questions if the retrieved chunks are labeled "Web Search Result".
7. **Tavily Web Search Fallback:** If the user asks about an out-of-scope jurisdiction (detected via regex `\b(fca|sec|...)\b`), or if FAISS returns zero chunks, the backend queries Tavily. Tavily chunks are formatted identically to FAISS chunks.
8. **RAG Evaluation Harness (Phase 1 RSI):** `eval/run_eval.py` runs a "Golden Dataset" of 10 hardcoded questions against `/api/chat`. It validates Retrieval (did it get the right doc?) and Groundedness (did the answer contain the right keywords?). It includes Unicode normalization to handle smart hyphens (`U+2011`) emitted by LLMs.
9. **Premium UI/UX:** Total dark mode, DeepSeek-style near-black palette. Tables render natively. **Source chips are full-width stacked cards** that wrap long web titles cleanly.
10. **Custom UI Popover:** Replaced native browser `<select>` for jurisdictions with a custom React popover (checkmarks, hover states, two-line detail) that matches the premium desktop feel on mobile.
11. **VARA Footer Sanitization:** `clean_vara_pdf_text()` strips bilingual footers. **CRITICAL:** The ingestion pipeline guards this (`_is_vara_document()`) so it does NOT strip article numbers from the EU AI Act.
12. **FAISS In-Memory Cache:** `retrieval.py` caches `_INDEX` and `_METADATA` at module level, saving ~530ms per query.
13. **Scroll-Jump Root-Cause Fix:** `App.jsx` uses `justSentRef` to prevent DB reloads. `ChatWindow.jsx` uses `scrollTo` on the container.

## 5. Roadblocks & Resolutions (Complete History)

1. **Render OOM (512MB)** → Migrated to Cohere Cloud Embeddings.
2. **Gemini Embedding Rate Limits (429)** → Cohere.
3. **VARA PDF Footer Contamination** → `clean_vara_pdf_text()`.
4. **First Ingest Duplicate Danger** → Skip-check logic in `ingest.py`.
5. **SSE Parse Error ("Unterminated string")** → `client.js` buffers chunks until `\n\n`.
6. **Slow Response (~2.5–4.5s TTFT)** → Module-level cache for FAISS, TOP_K hardcoded to 5.
7. **Session Lost on Refresh** → `currentSessionId` persisted in `localStorage`.
8. **Page Auto-Scrolls to Top During Streaming** → Fixed via `justSentRef` and `key={i}` on messages.
9. **Markdown Numbers & Bold Text Appear Blue** → Overrode global Tailwind `prose` styles.
10. **EU AI Act "Corpus covers VARA only" Refusal** → `SYSTEM_PROMPT` rewritten to be jurisdiction-neutral.
11. **EU AI Act Article Numbers Stripped** → Added `_is_vara_document()` guard in `ingestion.py`.
12. **Markdown Tables Rendered as Raw Pipes** → Installed `remark-gfm` and custom table overrides.
13. **Table Clipping on Mobile** → Added `w-full min-w-0` to the table wrapper.
14. **Ugly Native Mobile Dropdown** → Replaced `<select>` with custom React popover.
15. **Web Fallback Refusing Out-of-Scope Questions** → Added an exception in `SYSTEM_PROMPT` for "Web Search Result" chunks.
16. **Empty Query Rewriter Crash** → Fell back to `req.question` if the rewritten query is empty.
17. **"US" Substring Match Bug** → "Custody" triggered "us". Fixed by using regex `\b` (word boundaries).
18. **Source Chips Bleeding out of Bubble** → Switched to `flex-col` stacked cards with `break-words`.
19. **Groq Rate Limits in Eval** → The eval script fired questions too fast, hitting Groq's 8K TPM limit. Fixed by adding a 25-second sleep between tests and graceful fallback.
20. **Missing `source_url` in Non-Streaming API** → `/api/chat` stripped web URLs from the response, breaking the eval's web-detection logic. Fixed by adding `source_url: str = ""` to `SourceReference` in `schemas.py` and passing it in `routes.py`.
21. **Unicode Hyphen Eval Bug** → LLM output `general‑purpose` with a non-breaking hyphen (`\u2011`). Python string matching failed. Fixed by adding a Unicode normalizer in `run_eval.py`.
22. **Rewriter Truncation on 429** → Rewriter returned partial strings, causing garbage retrieval. Fixed by adding `_postprocess_rewrite` in `llm.py` to detect truncation and fall back to a sanitized version of the original question.
23. **Cross-Cutting Service Stripping Failure** → LLM ignored prompt instructions to strip "Custody provider" for AML questions. Fixed by adding deterministic regex stripping in `_postprocess_rewrite`.

### ⚠️ Security — RESOLVED
API keys rotated. `.strip()` applied. Browser history isolated per device. Clipboard sanitization prevents markdown leakage. External links use `rel="noopener noreferrer"`.

## 7. API Contract (Live on Render)

### `POST /api/chat` (Non-Streaming, used by Eval)
**Request:** `{"question":"...","jurisdiction":"EU","history":[]}`
**Response:** 
```json
{
  "answer": "...",
  "sources": [{"page": 53, "section": "...", "document": "...", "source_url": "..."}],
  "session_id": "...",
  "model_used": "..."
}
```

### `POST /api/chat/stream` (Streaming, used by Frontend)
**Response (SSE):**
- First chunk: `{"type": "sources", "sources": [{"page": 53, "section": "...", "document": "...", "source_url": "..."}]}`
- Subsequent chunks: `{"type": "text", "text": "word "}`

### `GET /api/jurisdictions`
**Response:** Returns the list of supported jurisdictions (`AE-Dubai`, `EU`) for the frontend dropdown.
