## 1. What We're Building

A **Retrieval-Augmented Generation (RAG) chat** for querying global regulatory rulebooks. The user picks a jurisdiction, asks a question, and the system retrieves the most relevant chunks from FAISS and BM25, passes them to an LLM with strict citation rules, and returns a grounded answer.

**The AI acts as a conversational compliance colleague.** It explains the "why" behind rules, uses analogies, and answers follow-up questions naturally—while still strictly anchoring every specific legal fact, date, and penalty to the retrieved sources. 

**If the answer isn't in the internal corpus, the system searches the live web via Tavily and Serper — restricted to authoritative sources.** If the web search returns nothing trusted, the app *honestly refuses* rather than hallucinating a citation.

## 4. Architecture & Design Decisions (Validated)

1. **Hybrid Search (BM25 + FAISS):** We use Reciprocal Rank Fusion (RRF) to merge semantic vectors from FAISS with exact keyword matches from BM25.
2. **The Critic Agent (Reflexion):** Before the answer streams to the user, a fast LLM checks for hallucinations and missing citations. If it fails, the system silently retries with a broader query.
3. **Perplexity-Style Source Drawer:** The frontend UI features a single "📚 X Sources" pill inside the chat bubble. Clicking it opens a slide-out panel (`SourceDrawer.jsx`) showing the exact snippets, authority tiers, and links, keeping the chat interface uncluttered.
4. **Conversational Synthesis Prompt:** The `SYSTEM_PROMPT` allows the AI to use analogies and explain concepts using general knowledge, while forcing it to anchor specific legal facts to the retrieved chunks.
5. **Role Classification Precision (EU AI Act):** The AI is explicitly instructed to distinguish between a **Provider** (who builds the model and does conformity assessments) and a **Deployer** (who hosts or integrates it). It is forbidden from misclassifying a hosting firm as a Provider.
6. **Draft Persistence:** Unsent text in the chat input is saved to `localStorage` per session. Refreshing the page restores the draft. "New Chat" drafts use `sessionStorage` to survive refresh but not new tabs.
7. **Phase 3 Evals (LLM-as-a-Judge):** The `eval/run_eval.py` script now uses a fast LLM to score answers (1-5) on accuracy and hallucination, not just keyword matching. `golden_dataset.json` has been expanded to 20 hard questions.
8. **Cohere Timeout Resilience:** `retrieval.py` now wraps the Cohere embedding call in a retry loop with a 15-second timeout and 2 retries. If Cohere is down, the API returns a friendly message instead of a 500 crash.
9. **SSE streaming** — `/api/chat/stream` yields Server-Sent Events; frontend buffers on `\n\n`.
10. **Cloud embeddings (Cohere)** — replaced local PyTorch to kill Render OOM bugs.
11. **Per-browser privacy (Supabase)** — unique `vara_browser_id` in `localStorage`.
12. **Conversational memory** — frontend sends smart window (first 2 + last 8); backend injects into prompt.
13. **Jurisdiction-aware query rewriter** — skips for short (<8 words) AND very long (>40 words) questions.
14. **Smarter Three-Trigger Web Fallback:** out-of-scope token, low FAISS confidence, post-generation LLM refusal detection.
15. **Dual-Provider Web Search:** Tavily first. If Tavily returns <2 results, Serper (Google) fires and merges the results. Trusted domains filtered.
16. **Honest refusal:** refuses rather than hallucinating when no authoritative source exists.
17. **Citation deep-linking:** `retrieval.py` appends `#page=X&search="phrase"` to PDF URLs, jumping users directly to the exact page.
18. **VARA Part Mapping:** `retrieval.py` maps page ranges to VARA "Part 1, Part 2" names.
19. **3-Tier LLM Waterfall:** Tier 1: Groq. Tier 2: OpenRouter. Tier 3: Google Gemini. Zero downtime.
20. **Token Ceiling Management:** `TOP_K_RESULTS` is set to 5. `LLM_MAX_TOKENS` is set to 1500.
21. **Dynamic Retrieval Broadening:** If FAISS returns low-confidence results, `retrieval.py` automatically performs a second search with filler words stripped out.
22. **Query Hints:** `config.py` has a `QUERY_HINT_MAP` to force retrieval of the Omnibus deadline, Article 50, and Cabinet Decision 111.
23. **Prompt Injection Guard:** The `SYSTEM_PROMPT` explicitly tells the LLM to refuse requests to "ignore previous instructions".
24. **Article Verification:** The LLM is forbidden from guessing article numbers. It cites by page if unsure.
25. **Cold-Start UX:** `client.js` waits 4 seconds for the first byte. If none arrives, it triggers an `isWarming` state that shows a "Warming up the AI…" spinner above the input.
26. **Cron Keep-Alive:** A cron-job.org job pings `/api/health` every 10 minutes to prevent Render's free-tier cold sleep.

## 6. Roadblocks & Resolutions (Complete History)

1-57. *(Previous history preserved as documented in prior STATE.md)*
58. **Role Misclassification (Provider vs. Deployer)** → Gemini's critique revealed the AI was calling a hosting firm a "Provider", which would trigger unnecessary conformity assessments. Fixed by adding `ROLE CLASSIFICATION PRECISION` to the prompt and the Critic.
59. **Draft Loss on Refresh** → Unsent text in the chat input was wiped on page refresh. Fixed by adding `localStorage` draft persistence.
60. **Cohere API Timeout Crashes** → During the Phase 3 eval, Cohere briefly became unreachable, causing a `ConnectTimeout` and a 500 HTTP error. Fixed by wrapping the Cohere embed call in a 2-retry loop with a 15-second timeout and friendly error handling.
61. **Cabinet Decision 111 vs 112 Confusion** → The AI was retrieving the wrong Cabinet Decision. Fixed by adding an explicit `QUERY_HINT_MAP` entry to force the exact title.
62. **Omnibus Date Retrieval (Partial Fail)** → The AI was refusing to give the 2 December 2027 deadline. Fixed by adding "2 December 2027" explicitly to the `QUERY_HINT_MAP` for deadline questions.
