## 1. What We're Building

A **Retrieval-Augmented Generation (RAG) chat interface** for querying regulatory rulebooks. A user types a question in a chat window; the system retrieves the most relevant chunks from regulatory PDFs, passes them to an LLM with strict citation rules, and returns a grounded answer with page references. 

**Why it exists:** Banks and VASPs struggle to navigate sprawling regulatory rulebooks. An uncited answer is worthless in compliance. This tool answers *only* from the documents, cites every claim, and refuses when the answer isn't in the source.

## 4. Architecture & Design Decisions (Validated)

1. **Streaming (SSE) Architecture:** The `/api/chat/stream` endpoint yields Server-Sent Events. The frontend reads the stream and updates the text word-by-word, eliminating the 5-10 second wait.
2. **Cloud Embeddings (Cohere):** Replaced Gemini (1000 req/day limit) with Cohere to eliminate rate limits and handle large batches (90 chunks per request) without crashing.
3. **Database Storage (Supabase):** Chat sessions and messages are saved in PostgreSQL via Supabase. Clearing browser cache no longer deletes chats.
4. **Premium UI/UX:** Total dark mode. Sidebar is deep navy (`#0F172A`). Main chat background is slightly lighter navy (`#1E293B`). Chat input is a glowing, rounded pill with brand blue contrast.
5. **Action Buttons:** Messages have copy, edit (for users), and thumbs up/down/share (for AI) with custom CSS tooltips.
6. **Provider-agnostic LLM.** Swap Groq → DeepSeek by editing `.env`. Zero code changes.
7. **Jurisdiction filter in metadata.** Adding a regulator = new PDFs + config entries.
8. **Reset-able ingestion.** `--reset` flag prevents duplicate vectors.
9. **Smart Titles.** A dedicated `/api/title` endpoint uses a lightweight model (`llama-3.1-8b-instant`) to generate a 3-5 word summary to populate the sidebar without hitting rate limits.
10. **TXT File Handling:** The ingestion script checks for `.txt` files first, reading them as a single massive page, before falling back to the `pypdf` library for `.pdf` files.

## 6. Roadblocks & Resolutions (Complete History)

1. **`notepad++` not recognized** → `start notepad++ "file"`. ✅
2. **`pip install` failed on Python 3.14** → Chroma's `chroma-hnswlib` link error. **Resolution:** swapped Chroma → FAISS, bumped pydantic ≥2.13.0. ✅
3. **`/api/chat` 502 `proxies` error** → `openai==1.54.0` vs `httpx>=0.28`. Bumped to `openai>=1.55.3`. ✅
4. **Markdown rendering issue** → Installed `react-markdown`. ✅
5. **Slow Response Time (Blocking)** → Implemented Server-Sent Events (SSE). ✅
6. **Input "Red Circle" Bug** → Ensured `preventDefault()` on the `Enter` keydown handler. ✅
7. **Clearing Cache Deletes Chats** → Migrated to Supabase PostgreSQL. ✅
8. **GitHub Push Protection Error** → Real API keys were accidentally committed. **Resolution:** Reset git history (`git init`), replaced the keys with placeholders, force-pushed. ✅
9. **Render Deployment Port Scan Timeout** → The Start Command `--port $PORT` wasn't expanding. **Resolution:** Wrapped the command in `sh -c "uvicorn ... --port $PORT"`. ✅
10. **Render Deployment Out of Memory (512MB)** → `sentence-transformers` loaded PyTorch at startup. **Resolution:** Migrated to Google Gemini Cloud Embeddings. ✅
11. **Gemini Embedding Rate Limit (429)** → Free tier limit is 100 requests per minute / 1000 per day. **Resolution:** Migrated to Cohere. ✅
12. **`"PDF not found"` during Ingestion** → The actual `.txt` files for the Company, Technology, and Market Conduct rulebooks were not saved in the `backend/data/` folder. **Resolution:** Created the files via Notepad++ and updated `ingestion.py` to read `.txt` files natively. ✅
