## 1. What We're Building

A **Retrieval-Augmented Generation (RAG) chat interface** for querying regulatory rulebooks. A user types a question in a chat window; the system retrieves the most relevant chunks from a regulatory PDF, passes them to an LLM with strict citation rules, and returns a grounded answer with page references. 

**Why it exists:** Banks and VASPs struggle to navigate sprawling regulatory rulebooks. An uncited answer is worthless in compliance. This tool answers *only* from the document, cites every claim, and refuses when the answer isn't in the source.

**First case study:** VARA (Dubai Virtual Assets Regulatory Authority) — Compliance and Risk Management Rulebook, 19 May 2025.
**Design goal:** Multi-jurisdiction from day one. Adding CBN (Nigeria), FCA (UK), or SEC (US) later must require zero backend code changes.

## 4. Architecture & Design Decisions (Validated)

1. **Streaming (SSE) Architecture:** The `/api/chat/stream` endpoint yields Server-Sent Events. The frontend reads the stream and updates the text word-by-word, eliminating the 5-10 second wait.
2. **Cloud Embeddings (Gemini):** Replaced local `sentence-transformers` with Gemini to eliminate PyTorch and fit within Render's 512MB free-tier RAM limit.
3. **Database Storage (Supabase):** Chat sessions and messages are saved in PostgreSQL via Supabase. Clearing browser cache no longer deletes chats.
4. **Premium UI/UX:** Total dark mode. Sidebar is deep navy (`#0F172A`). Main chat background is slightly lighter navy (`#1E293B`). Chat input is a glowing, rounded pill with brand blue contrast.
5. **Action Buttons:** Messages have copy, edit (for users), and thumbs up/down/share (for AI) with custom CSS tooltips.
6. **Provider-agnostic LLM.** Swap Groq → DeepSeek by editing `.env`. Zero code changes.
7. **Jurisdiction filter in metadata.** Adding a regulator = new PDF + one config entry.
8. **Reset-able ingestion.** `--reset` flag prevents duplicate vectors.
9. **Smart Titles.** A dedicated `/api/title` endpoint uses a lightweight model (`llama-3.1-8b-instant`) to generate a 3-5 word summary to populate the sidebar without hitting rate limits.

## 6. Roadblocks & Resolutions (Complete History)

1. **`notepad++` not recognized** → `start notepad++ "file"`. ✅
2. **BIGGEST: `pip install` failed on Python 3.14** → Chroma's `chroma-hnswlib` link error. **Resolution:** swapped Chroma → FAISS, bumped pydantic ≥2.13.0. ✅
3. **`/api/chat` 502 `proxies` error** → `openai==1.54.0` vs `httpx>=0.28`. Bumped to `openai>=1.55.3`. ✅
4. **Markdown rendering issue** → The LLM returned `**bold**`, but UI showed raw asterisks. **Resolution:** Installed `react-markdown`. ✅
5. **Slow Response Time (Blocking)** → Waiting 5-10 seconds for the LLM to finish. **Resolution:** Implemented Server-Sent Events (SSE) with `StreamingResponse`. ✅
6. **Input "Red Circle" Bug** → HTML5 form validation blocked the text area. **Resolution:** Ensured `preventDefault()` on the `Enter` keydown handler. ✅
7. **Clearing Cache Deletes Chats** → `localStorage` is wiped by browser cache clears. **Resolution:** Migrated to Supabase PostgreSQL. ✅
8. **GitHub Push Protection Error** → Real API keys were accidentally committed. **Resolution:** Reset git history (`git init`), replaced the keys with placeholders, force-pushed. ✅
9. **Render Deployment Port Scan Timeout** → The Start Command `--port $PORT` wasn't expanding. **Resolution:** Wrapped the command in `sh -c "uvicorn ... --port $PORT"`. ✅
10. **Render Deployment Out of Memory (512MB)** → `sentence-transformers` loaded PyTorch at startup, exceeding 512MB. **Resolution:** Migrated to Google Gemini Cloud Embeddings, removing PyTorch entirely. ✅
11. **Gemini Embedding Rate Limit (429)** → Free tier limit is 100 requests per minute. Batching 202 chunks too fast triggered the limit. **Resolution:** Added a 60-second sleep between batches of 40 chunks. ✅
12. **Render Backend 500 Error `No API_KEY or ADC found`** → `GEMINI_API_KEY` is missing in Render's Environment Variables. **Resolution:** Added `GEMINI_API_KEY` to Render dashboard. ✅
