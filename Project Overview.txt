## 1. What We're Building

A **Retrieval-Augmented Generation (RAG) chat interface** for querying regulatory rulebooks. A user types a question in a chat window; the system retrieves the most relevant chunks from a regulatory PDF, passes them to an LLM with strict citation rules, and returns a grounded answer with page references. 

**Why it exists:** Banks and VASPs struggle to navigate sprawling regulatory rulebooks. An uncited answer is worthless in compliance. This tool answers *only* from the document, cites every claim, and refuses when the answer isn't in the source.

**Current Corpus:** VARA Compliance and Risk Management Rulebook (19 May 2025). 
*(Note: The Company, Technology, and Market Conduct rulebooks were removed to ensure absolute stability for the demo. The architecture remains fully capable of scaling to all rulebooks post-demo).*

## 4. Architecture & Design Decisions (Validated)

1. **Streaming (SSE) Architecture:** The `/api/chat/stream` endpoint yields Server-Sent Events. The frontend reads the stream and updates the text word-by-word.
2. **Cloud Embeddings (Cohere):** Replaced Gemini to bypass hard rate limits.
3. **Database Storage & Privacy (Supabase):** Chat history is saved via Supabase. A unique `vara_browser_id` is generated in `localStorage` for every new browser. When Terry opens the link, he gets a fresh, private session, completely isolated from your history.
4. **Premium UI/UX:** Total dark mode. Sidebar is deep navy. Chat input is a glowing, rounded pill.
5. **Mobile Responsiveness:** Added a hamburger menu to toggle the sidebar on mobile devices. Cleaned up the header alignment and source pills.
6. **Action Buttons:** Messages have copy, edit (for users), and thumbs up/down/share (for AI).
7. **Reset-able ingestion.** `--reset` flag prevents duplicate vectors.
8. **Smart Titles.** `/api/title` uses `llama-3.1-8b-instant` for fast sidebar titles.

## 6. Roadblocks & Resolutions (Complete History)

1. **`notepad++` not recognized** → `start notepad++ "file"`. ✅
2. **`pip install` failed on Python 3.14** → Chroma's `chroma-hnswlib` link error. **Resolution:** swapped Chroma → FAISS, bumped pydantic ≥2.13.0. ✅
3. **`/api/chat` 502 `proxies` error** → `openai==1.54.0` vs `httpx>=0.28`. Bumped to `openai>=1.55.3`. ✅
4. **Markdown rendering issue** → Installed `react-markdown`. ✅
5. **Slow Response Time (Blocking)** → Implemented Server-Sent Events (SSE). ✅
6. **Input "Red Circle" Bug** → Ensured `preventDefault()` on the `Enter` keydown handler. ✅
7. **Clearing Cache Deletes Chats** → Migrated to Supabase PostgreSQL. ✅
8. **GitHub Push Protection Error** → Real API keys were accidentally committed. **Resolution:** Reset git history, replaced keys with placeholders. ✅
9. **Render Deployment Port Scan Timeout** → Wrapped the command in `sh -c "uvicorn ... --port $PORT"`. ✅
10. **Render Deployment Out of Memory (512MB)** → `sentence-transformers` loaded PyTorch at startup. **Resolution:** Migrated to cloud embeddings. ✅
11. **Gemini Embedding Rate Limits (429)** → Migrated to Cohere. ✅
12. **Cohere API Key Header Error** → Trailing newline in Render env var caused `Illegal header value`. **Resolution:** Added `.strip()` to `config.py` and fixed Render dashboard. ✅
13. **Corrupted Text Encoding** → Notepad++ saved `.txt` files in ANSI/UTF-16. **Resolution:** Reverted to the stable 202-chunk Risk Management PDF. ✅
14. **Shared Chat History** → `guest-user-001` hardcoded, exposing your chats to anyone with the link. **Resolution:** Implemented unique `vara_browser_id` in `localStorage` for every new browser. ✅
