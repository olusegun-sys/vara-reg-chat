## 1. What We're Building

A **Retrieval-Augmented Generation (RAG) chat** for querying global regulatory rulebooks. The user picks a jurisdiction, asks a question, and the system retrieves the most relevant chunks from FAISS and BM25, passes them to an LLM with strict citation rules, and returns a grounded answer.

**The AI acts as a conversational compliance colleague.** It explains the "why" behind rules, uses analogies, and answers follow-up questions naturally — while strictly anchoring every legal fact to the retrieved sources.

**If the answer isn't in the internal corpus, the system searches the live web via Tavily and Serper — restricted to authoritative sources.** If the web search returns nothing trusted, the app *honestly refuses* rather than hallucinating a citation.

**Strategic Reality Check:** This is a strong seed-stage POC, not a $1B company yet. To reach that valuation, we need: real ARR, a defensible moat, a technical co-founder, and enterprise compliance (SOC 2). The immediate next step is a demo to Terry, not a VC pitch.

## 4. Architecture & Design Decisions (Validated)

1. **Hybrid Search (BM25 + FAISS):** Reciprocal Rank Fusion (RRF) merges semantic vectors from FAISS with exact keyword matches from BM25.
2. **The Critic Agent (Reflexion):** Before the answer reaches the user, a **fast LLM check** flags hallucinations and missing citations. **Fails open** — if the Critic can't run (network, quota, empty response), the answer ships anyway so users are never blocked by the Critic itself.
3. **Perplexity-Style Source Drawer:** "📚 X Sources" pill in the chat bubble → slide-out panel with exact snippets, authority tiers, and deep links.
4. **Conversational Synthesis Prompt:** The AI uses analogies and explains the "why", while strictly anchoring every specific legal fact to a retrieved chunk.
5. **Role Classification Precision (EU AI Act):** The AI distinguishes **Provider** (does conformity assessments) from **Deployer** (hosts/integrates it).
6. **Draft Persistence:** Unsent text is saved to `localStorage` per session.
7. **Phase 3 Evals (LLM-as-a-Judge):** `eval/run_eval.py` scores answers 1–5 on accuracy and hallucination. `golden_dataset.json` has 20 hard questions.
8. **Cohere Timeout Resilience:** `retrieval.py` wraps the Cohere embed call in a 2-retry loop with 15-second timeout.
9. **SSE streaming with heartbeat:** `/api/chat/stream` yields SSE events; during long blocking phases (LLM call, Critic call) the backend emits `: keep-alive\n\n` comments every 2 seconds. This prevents the browser from aborting the connection during the silent gap. **Header changes:** `Cache-Control: no-cache`, `Connection: keep-alive`, `X-Accel-Buffering: no`. **Uvicorn startup:** `--timeout-keep-alive 120`.
10. **Cloud embeddings (Cohere)** — replaced local PyTorch to kill Render OOM bugs.
11. **Per-browser privacy (Supabase)** — unique `vara_browser_id` in `localStorage`.
12. **Conversational memory** — smart window (first 2 + last 8) to the LLM.
13. **Jurisdiction-aware query rewriter** — skips for short (<8 words) AND very long (>40 words) questions.
14. **Smarter Three-Trigger Web Fallback:** out-of-scope token, low FAISS confidence, post-generation LLM refusal detection.
15. **Dual-Provider Web Search:** Tavily first. If Tavily returns <2 results, Serper fires and merges.
16. **Honest refusal:** refuses rather than hallucinating when no authoritative source exists.
17. **Citation deep-linking:** `retrieval.py` appends `#page=X&search="phrase"` to PDF URLs.
18. **VARA Part Mapping:** `retrieval.py` maps page ranges to VARA "Part 1, Part 2" names.
19. **3-Tier LLM Waterfall (CURRENT ORDER):** **Groq → Gemini → OpenRouter**. (This is the reverse of the pre-2026-11-08 order. Gemini moved up because its daily limits are the most generous of the three, and because Groq's 200k-token cap is the most likely tier to be exhausted.)
20. **Token Ceiling Management:** `TOP_K_RESULTS = 5`. `LLM_MAX_TOKENS = 1500`. Critic `max_tokens = 200` with `reasoning_effort="low"`.
21. **Dynamic Retrieval Broadening:** Low FAISS confidence triggers a broader keyword search.
22. **Query Hints:** `QUERY_HINT_MAP` forces retrieval of the Omnibus deadline, Article 50, and Cabinet Decision 111.
23. **Prompt Injection Guard:** Refuses "ignore previous instructions" requests.
24. **Article Verification:** Forbids guessing article numbers; cites by page if unsure.
25. **Cold-Start UX:** `client.js` waits 4 seconds, then shows "Warming up the AI…".
26. **Cron Keep-Alive:** cron-job.org pings `/api/health` every 10 minutes.
27. **Critic portability warning:** `reasoning_effort="low"` is **Groq-specific**. If the Critic is ever routed to Gemini or OpenRouter, that parameter must be branched out (it will 400 on those providers).

## 6. Roadblocks & Resolutions (Complete History)

1–61. *(Previous history preserved as documented in prior STATE.md)*
62. **Cohere API Timeout Crashes** → Cohere briefly became unreachable, causing a `ConnectTimeout` and 500. Fixed with 2-retry loop, 15-second timeout.
63. **Deprecated Model Names** → OpenRouter retired Llama 3 (70b), Google retired Gemini 1.5-flash. Fixed by updating to `meta-llama/llama-3.3-70b-instruct:free` and `gemini-2.0-flash`.
64. **🟢 Omnibus Date Retrieval (partial fix)** → The AI refused to give the 2 December 2027 deadline because chunking split the date away from the main Omnibus text. Fixed locally by adding "2 December 2027" to `QUERY_HINT_MAP`. (Real fix is Article-Aware chunking — deferred.)
65. **🟢 ERR_INCOMPLETE_CHUNKED_ENCODING on long streams** → Root cause: silent gap while `generate_answer` + `critic_check` run exceeded Uvicorn's `timeout_keep_alive` default (5s). Fixed by **(a)** SSE response headers (`Cache-Control: no-cache`, `Connection: keep-alive`, `X-Accel-Buffering: no`), **(b)** `uvicorn --timeout-keep-alive 120`, **(c)** heartbeat SSE comments (`: keep-alive\n\n`) every 2s during blocking LLM calls via `ThreadPoolExecutor` in `stream_answer`. **Verified end-to-end** — no more chunked-encoding errors.
66. **🟢 Deprecated `google.generativeai` SDK** → `ImportError: cannot import name 'genai' from 'google'`. Root cause: `google-generativeai` (old package) was still installed, not `google-genai` (new package). Fixed by `pip uninstall google-generativeai -y` + `pip install google-genai`, then migrating `llm.py` to use `genai.Client(...)` and `client.models.generate_content(contents=..., config=GenerateContentConfig(system_instruction=...))`. **Verified end-to-end.**
67. **🟢 `gemini-2.0-flash` was shut down (June 1, 2026)** → Updated `GEMINI_MODEL` to `gemini-3.8-flash` (released Sept 2, 2026, no shutdown date announced). **Verified end-to-end.**
68. **🟢 Critic Agent empty response (`content=''`)** → Diagnostic revealed `finish_reason=length`, `reasoning_tokens=47` out of `max_tokens=50`. Root cause: `openai/gpt-oss-120b` is a reasoning model; without `reasoning_effort="low"` it burns the token budget on hidden reasoning and never emits PASS/FAIL. Fixed by adding `reasoning_effort="low"` + raising `max_tokens` to 200. Added empty-response guard that fails open (returns `True`). **Verified in the diagnostic, but not yet verified in a real end-to-end query** (blocked by Groq quota on the day of the fix).
69. **🟢 OpenRouter 404 on `meta-llama/llama-3-70b-instruct`** → Root cause: `.env` had a stale override pointing at the retired model. `config.py` default was already correct. Fixed by changing `.env` line to `BACKUP_LLM_MODEL=meta-llama/llama-3.3-70b-instruct:free`. Verified via `config.BACKUP_LLM_MODEL` in a fresh Python process. **Not yet verified end-to-end** (blocked by Groq quota; OpenRouter tier only fires when Groq AND Gemini both fail).

**Security — RESOLVED:** API keys rotated; `.strip()` on all env reads; per-browser history isolation; external links use `rel="noopener noreferrer"`; `.env` in `.gitignore`; prompt injection guard active.
